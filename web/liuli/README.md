# 琉璃 · 长卷

**时间是一块连续的空间画布，你在地图上看自己的日子。** 不是列表、不是聊天
记录 —— 是一张可以拖、可以捏合的图。

## 跑起来

```bash
npm install && npm run dev      # http://localhost:5177
npm run build                   # tsc + vitest + vite build
```

## 三个范式，三个「现在」，一个都没借

| | 「现在」是什么 |
|---|---|
| 汀 | **那一件** —— 屏幕上唯一该显示的东西 |
| 纸屿 | **一个位置** —— 流里画线的地方 |
| 长卷 | **一个坐标** —— 每个块都有 y、高度、层级 |

这是共享层停在对的地方的证据：三个前端的共同点是**怎么跟后端说话**，不是
它们认为一天是什么。`packages/core` 给 HTTP、握手、多语言、地址配置；
`src/canvas.ts` 是长卷 自己的。

## ⚠️ 几何里的三条硬规则

**分层按「先开始、同分钟长的在前」。** 反过来的话，和短块同时开始的长块会落
到更高的层、画在它包住的东西上面 —— 短块消失在长块后面，那正好是分层要避免
的。

**最小高度是地板不是建议。** 一个 5 分钟的块在任何合理缩放下只有几像素高，
手指点不到。低于那条线，块不是变短了而是**不存在了**。

**虚影和真实块一起分层。** 分开算的话虚影可能落到 0 层被真实块盖住 —— 而一个
读不清的提案是这个设计唯一不能出的错。虚影的 zIndex 也因此高于真实块。

## ⚠️ 引力井：按最近角落，不是按象限

象限判定加上放宽的 pad 会在中线附近造出一块**两个井都声称拥有**的重叠区，而
第一版是靠 `if` 的书写顺序解决的 —— 那是意外不是决定。改成最近角落之后没有
歧义区：放宽让目标更好命中，而不是让它赢得平局。

⚠️ 手指和指针的修正**方向相反**：手指不精确但它的目标是它**盖住**的东西，所以
把范围**收窄**（负 pad），否则一次只是路过角落的拖拽会被捕获；指针精确但很小，
所以把范围**放宽**。

## ⚠️ 「现在」那条线是均匀 1.5px 实线

早期用横向渐变，结果左粗右消、视觉偏心。一条表示「现在」的线不能看起来像
「大致现在」。

## 它需要一种第三档 kind

`--cj-ghost-inset` 是**比例或长度** —— 内置六种里没有一种是两个原语的并集，
组合子也表达不了并集。所以提议 `ratio-or-length`。

⚠️ 但 `--cj-ghost-dash` 用的是 `list-of<length>`，一个**已有的组合子**，
所以长卷 对它**什么都不提议**。有一条断言专门钉这个：一个提议了它并不需要的
kind 的前端，会平白往运维桌上放一个决定，而第三档只在这种事很少发生时才便宜。
