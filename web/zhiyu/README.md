# 纸屿 · 顺流

**一天是一篇由你和小禾共同书写的日志。** 向上滚是过去，向下滚是预告 ——
滚动本身就是时间旅行。导航退化为一个「回到现在」按钮。

关键区别：这是**账本渲染流**，不是聊天记录。每条是一个事件卡而不是气泡；
足迹与今天是同一条流的不同滚动位置，**没有「历史页」**。

## 跑起来

```bash
npm install
npm run dev          # http://localhost:5176
npm run build        # tsc + vitest + vite build
```

## 和汀 共享什么、不共享什么

`@daycore/core` 给了 HTTP、握手、多语言、后端地址配置。**没给「现在是什么」**——
`src/stream.ts` 是纸屿 自己的：汀 要的是「该显示哪一件」，纸屿 要的是「线画在
哪儿」。同一个后端、同一批 block，问的是两个问题。把它提到共享包里，就是让
两个范式里的一个去借另一个的「现在」，而借来的那个永远微妙地不对。

## ⚠️ 纸就是纸

噪声全部去掉。这是踩过两次的坑（HANDOFF 03 §3）：追求「纸质感」堆噪声的结果
是**完全不像纸**。真实的纸在屏幕上就是干净的纯色加极淡的规则线条。

`--dc-line` 要非常淡（墨色的 4%~9%），加重它会立刻变成表格。

## ⚠️ 它需要两种第三档 kind

`--dc-ease` 是 `cubic-bezier(…)`，`--dc-r-*` 是长度**或**百分比（`--pin-shape: 50%`
就是圆）—— 内置六种一种都表达不了。所以纸屿 提议 `easing` 和 `radius` 两个 kind。

这是**第二个**独立前端第一天就落到这个位置上。第三档不是边缘情况。

`internal/theme/frontend_manifest_test.go` 把两条 pattern 从这个 manifest 里
**读出来**（不是抄），喂进后端真正的注册表，再拿 `theme.css` 里真正的取值去验。
pattern 用 TypeScript 写、用 Go 执行，那个测试是两边唯一见面的地方。

⚠️ `easing` 里**故意不含 `steps()`**：它产生的是可见地不同**种类**的运动，
一个能悄悄把所有过渡变成卡顿的主题是能弄坏产品而不是重新配色的主题。

## ⚠️ 没有乐观更新，而且比汀 更要紧

汀 一次显示一件，过时的条目是一屏错的；纸屿 一次显示一整天，过时的条目坐在
一本看起来权威的账本里 —— 而「账本就是发生过的事」正是这个范式的全部前提。

## 一个被闸门抓到的设计问题

`hourLabel` 第一版返回显示字符串（`"09:00"` 或字面量 `"未定时"`），视图再拿
那个中文字面量去比较、决定要不要翻译。i18n 闸门报了它：**数据层里的显示关切**，
而且那个比较会在有人改措辞的那天悄悄失配。改成返回结构，这一层从此不命名
任何读者看得见的东西。
