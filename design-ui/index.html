DAYCORE · API v2.3

一套账本，五种活法

替不擅长规划的人省心的 AI 日程管家。下面是 五个范式级不同的前端——去掉颜色和文字，仅凭骨架也认得出谁是谁。它们消费同一套契约、共用同一份本地演示账本：在任一端接受的提案、撤销的动作，其余四端都看得见。

LIULI · 长卷

琉璃玻璃拟态 · 时间画布

时间是一块连续的空间画布，你在地图上看自己的日子。五席书签，今天居中放大；拖起一个块，四个引力井呼吸发光。
主表面 = 可拖拽的垂直时间轴（捏合到周为止）；提案投成轴上的虚影；四缘抽屉：资料·足迹·展望·伙伴。
进入长卷→
 ZHIYU · 顺流

纸屿纸感手帐 · 叙事流

一天是一篇由你和小禾共同书写的日志。向上滚是过去，向下滚是预告，滚动本身就是时间旅行。
主表面 = 单条账本渲染流（不是聊天史）；足迹与今天是同一条流的不同滚动位置；导航退化为「回到现在」。

 TING · 此刻

汀水边夜色 · 单件流

画面永远只回答一个问题：现在做什么。上滑送走一件事，提案整屏浮上来，一滑接受、一滑推开。
主表面 = 全屏一张当前块卡，下一件在底部露头；概览被刻意折叠成下拉抽屉——是抽屉，不是家。
进入此刻→
 LIULI · 初版

琉璃初版常规范式 · 页面制

最老实的那一版：底部标签栏、今天／资料／心情／伙伴四个页面，一屏一件事。没有画布，也没有手势——所有能力都摆在明面上。
主表面 = 纵向卡片列表 + 固定 Tab 导航；提案是列表里的一张待批卡。已接入共享账本（日程·作业·心情·资料·主题同步），作为对照组看清另外三个「非常规」到底非常规在哪。

 JING · 远路

径黎明公路 · 纵深时间

时间不是轴也不是流——是一条从脚下伸向地平线的路。事从远处走近，路过你身边时最大；下拉回头，是石化成碑的足迹。
主表面 = 纵深投影的公路场景（距现在的时长 → 路上的远近）；提案 = 路标虚影；死线压成天际线山脊；下拉 110px 镜头 180° 回头进足迹。四端基因的新组合：琉璃的空间、纸屿的连续、汀的聚焦。

演示场景

场景写进共享账本，五端同时生效。健康日：十几件静默、两三处显影、两张卡；危机日：两条死线打架 + 一条 20 小时未合眼的关怀；冷启动：无欢迎页、无强制导入——空状态即引导。铁律不变：不变红、不积债、任何 AI 动作 3 秒内可撤。
