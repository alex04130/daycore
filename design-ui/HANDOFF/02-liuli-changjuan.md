# 02 · 琉璃 · 长卷（时间画布）

> 源码：`liuli/index.html` + `liuli/app/{cj-main,cj-canvas,cj-parts,cj-drawers,cj-settings}.jsx` + `changjuan.css` + `app.css`
> 运营台：`liuli/admin.html`（独立页，沿用旧版）

## 范式一句话

**时间是一块连续的空间画布，你在地图上看自己的日子。** 不是列表、不是聊天记录——是一张可以拖、可以捏合、可以往上扔东西的图。

> ⚠ **`.cj-bottom` 与 `.cj-top` 必须 `pointer-events:none`，只有其子元素 `auto`。** 它们是全宽浮层，否则会在时间轴底部 176px 形成隐形挡板，虚影和块都点不到、拖不动。同理 `.cj-wells`。

## 2. 时间轴几何

- `PXM` = 每分钟像素数（缩放时变化）；`yOf(min) = (min − DAY0) * PXM`。
- 可见范围 `DAY0..DAY1`（默认 06:00–24:00），捏合可缩到"周透镜"（`.cj-week`：7 列，块变成小色条）。
- 块：`left: 46 + lane*18, right: 6`，`top: yOf(start)`，`height: max(30, dur*PXM − 2)`。`lane` 由 `laneize()` 算重叠层级，形成**层叠卡**（`.stacked` 加投影），不是并排分栏。
- **虚影与真实块一起 laneize**，虚影拿到 `zIndex: 14 + lane` 且底色不透明 + 1.5px 描边——否则会被真实块盖住读不清。
- `h < 48px` 的块进 `.compact` 模式：隐藏时长行与标签。
- 「现在」线：**均匀 1.5px 实线，`opacity:.55`**。早期用 `linear-gradient(90deg, accent, transparent)` 导致左粗右消、视觉偏心，已废弃。

## 3. 拖拽与手势（`onDown` / pointermove / pointerup）

| 行为 | 规格 |
|---|---|
| 起拖阈值 | 位移 > 5px |
| 长按开菜单 | **460ms**，未移动才触发；触发时 `navigator.vibrate(12)` |
| 桌面右键 | `onContextMenu` → 同一个浮层，`preventDefault` + 取消拖拽 |
| 石化块 | 往后拖直接拒绝，提示「过去的记录不改写——用『重新安排』放个新的」 |
| `hard` 锁块 | 只跟手 `max(-7, min(7, dy))`，位移 > 10px 时触发一次 `.tug` 回弹动画（440ms）+ toast 说明原因与替代动作 |
| 落进引力井 | 命中判定：**手机 `pad = -10`（内缩），桌面 `pad = 18`（放宽）** |

**引力井 2×2 对称**（早期只有三个，视觉不对称）：

| 位置 | 井 | 行为 |
|---|---|---|
| 左上 `.tl` | 资料收好 | 转成 material |
| 左下 `.bl` | 改天再说 | 转成 wish |
| 右上 `.tr` | 交给明天 | `moveBlock(+1d)` |
| 右下 `.br` | 小禾重排 | `proposeReschedule` |

- 桌面（≥701px）：体量放大（padding 14/16，halo 42px，字号 12.5），垂直收到 38%/32% 让四井靠近中线——鼠标好操作。
- 手机（≤700px）：缩小（padding 10/9，halo 30px，字号 10.5，max-width 74px），贴边 8px，判定内缩 10px 防误触。

## 4. 块上的三件东西

**① 灰色小锁 `.cj-lock`**（不是图钉——图钉在纸屿）
纯 CSS：`9×7px` 圆角矩形锁体 + `::before` 画半圆锁梁。变量：`--lock-c`（默认 `--ink3`）、`--lock-sz`、`--lock-op`、`--lock-radius`，全部在 `:root`，**AI 生成主题时可覆盖**。`hard` 实心，`soft` 透明度 ×0.55。

**② 右侧打勾圈 `.cj-tick`** — 26px 圆，**二态**：空 → ✓完成 → 空。
「没做」不进循环（它本来就是默认状态，不需要用户手动标）。
关键：`onPointerDown` 必须 `stopPropagation() + preventDefault()`，否则被拖拽逻辑抢走，点不动。

**③ 标签 `.cj-tags`** — 左下角，`slice(0, 3)` 硬上限，`nowrap + overflow:hidden`：
`[我放的|小禾排的]`、`[课表固定|约好的]`、`[待回顾|有注释]`。compact 卡隐藏。

## 5. 块浮层 `.cj-pop`（右键 / 长按 / 点击呼出）

自上而下：

1. 标题 + 元信息（时间、时长、来源）
2. **锁定块专属**（`lockLevel && phase !== 'stone'`）：一行「请假 / 不去」+「标记冲突」——**任何阶段都有，是快捷键级别的入口**
3. `hard` 锁：说明行「{lockReason}——时间不由你定，但你可以不去。」+ 完成了 / 请假 / 标记冲突
4. 非 hard：完成了 / 放到明天（soft 锁弹二次确认）/ 往后挪 30 分钟 / 移走
5. **标记区 `.cj-marks`**：`[完成了][没做（没关系）]` 二选一，点已选中的取消
6. **过期未标记专属**（`phase === 'recon' && status === 'planned'`）`.cj-lapse`：
   「这段过去了，还没标——它该去哪儿？」+ 三条出路：放回想做的事 / 明天再排 / 就这样过去
7. 石化块：「已经翻篇成记录——过去不改写，想补就用『重新安排』」+ 重新安排
8. 注释输入框

**打勾圈与浮层的标记必须是同一套状态**，不能一个二态循环一个不可逆——早期版本两套逻辑打架。

## 6. 四缘抽屉 `.cj-drawer`

左 = 资料、右 = 展望、上 = 足迹、下 = 伙伴（陪伴对话）。`.cj-veil` 遮罩 `blur(6px)`。从边缘滑出，`--spring` 曲线 320ms。
