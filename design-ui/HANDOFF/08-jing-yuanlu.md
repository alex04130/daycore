# 08 · 径 · 远路（地平线纵深时间）

> 源码：`jing/index.html` + `jing/app/{jing-parts,jing-scene,jing-panels,jing-main}.jsx` + `jing.css`
> 第五端。消费 `core/daycore-core.js` 同一份共享账本，无 admin 运营台。

## 范式一句话

**时间不是轴、不是流、不是卡——是一条从脚下伸向地平线的路，你往前走，事从远处走近。**

它是四端基因的一次新组合：琉璃的空间感（但纵深而非平面画布）、纸屿的连续时间（张望即时间旅行）、汀的此刻聚焦（最近的碑放大成主视觉卡）。距离即打扰等级——L0 在左上角安静小数字里，L1 虚影是路上的路标，L2 卡是场景前浮起的一张纸。

## 1. 骨架（去掉颜色也认得出）

```
┌─ .jg-top（z 40，pointer-events:none，子元素 auto）───────────┐
│  径 · 日期        [悄悄做了 N 件]      [心情][资料][伙伴][设置]│
├─ .jg-scene（全屏场景，绝对定位世界）─────────────────────────┤
│  .jg-sun 天体          ╱￣￣山脊￣￣╲  ← .jg-ridge（死线剪影）│
│  ═══════════════ 地平线（38.4% 视口高）══════════════════    │
│   \  .jg-road（透视梯形，收束到消失点）                     /  │
│    \   ▏碑▏（近大）        ▏碑▏（远小，贴地平线）           /  │
│     \  ▏虚影路标▏（半透明虚线，想放这儿?）                 /   │
│  .jg-now 现在立足点（底部 91% 处光环 + 时刻）                  │
├─ .jg-nowcard（z 30，此刻聚焦卡：最近一件 + 完成了/改期）──────┤
├─ .jg-bottom（z 45，pointer-events:none，子元素 auto）────────┤
│  [ 说一句话，我把它铺成路…                              ↑ ]   │
└──────────────────────────────────────────────────────────────┘
```

> ⚠ `.jg-top` / `.jg-bottom` 必须 `pointer-events:none`，子元素 `auto`——全宽浮层不这么做会形成隐形挡板（与琉璃同一条踩过的坑）。

## 2. 投影函数（本案的心脏，改数值等于改产品）

`viewMin`（距镜头分钟数）→ 屏幕：

```
HORIZON = 38.4（% 视口高）   BOTTOM = 91   K = 2.1（小时，透视常数）
z = viewMin / 60
p = z ≤ 0 ? max(-0.13, z·0.22) : min(0.93, z/(z+K))   // 渐近地平线，永不到达
y = BOTTOM − p·(BOTTOM − HORIZON)     scale = max(.16, 1 − p·.88)
opacity = max(.16, 1 − p·.82)
```

- 可见窗：`view ∈ (-55, 1560)` 分钟（身后 55 分钟 → 前方 26 小时，明天清晨贴着地平线）。
- **路半宽** `roadHalf(p) = (1−p)·30 + 2.6`（% 视口宽）；碑沿两肩交替站位：`laneX = 50 ± roadHalf·(0.6 + 0.34·⌈lane/2⌉)`，lane 由时间重叠递增（与琉璃 `laneize` 同思路，但站路肩不层叠）。
- `scale < 0.52` 进 `.compact`：隐藏时长行与标签，标题单行省略。
- 碑 `zIndex = round(y·10)`——近的盖远的；拖动中 +500。
- 偏移动画：`.jg-stele` 的 `left/top/opacity` 带 260ms 过渡——张望与「回到现在」自带滑翔。

## 3. 手势与镜头

| 行为 | 规格 |
|---|---|
| 背景上拖 / 滚轮下 | 镜头向前看（offset += ，上限 960 分钟）；now 不动，路从脚下伸向远处 |
| 背景下拖（offset≈0 时） | 拉穿 110px → **回头**：切入 `.past` 足迹镜像面（本端独有的导航动作） |
| 闲置 8 秒 | offset 自动归 0（回到现在）；offset>0 时浮「回到现在」chip |
| 点碑 / 长按 460ms / 右键 | 碑菜单（`.jg-pop`），长按触发 `vibrate(12)` |
| 拖碑 | 改期：≈3px/分钟、5 分钟一档；`hard` 锁只跟手 ±7px，位移 >10px 触发一次 `.tug` 回弹（440ms）+ toast 给替代动作 |
| 键盘（桌面） | ↑/↓ 张望、Enter 此刻卡主动作、Esc 关浮层 |

## 4. 碑的三种材质（材质即语义）

| 态 | 视觉 | 可做什么 |
|---|---|---|
| 未来（木牌） | 类型色 13% 底 + 左侧 4px 色条；manual 实线框 / auto 虚线框（三线语义） | 全部动作 |
| 此刻 | 外圈 `accent 32%` 光晕 | 同上 |
| 石化（石碑） | `saturation` 归零的灰石质感，色条变 `--ink3`，无投影 | 只读：注释 / 重新安排（`proposeReschedule` 提案到明天） |

- **锁**：hard/soft 非石化碑左上角浮 `.lk-ic` 小锁（soft 透明度 ×0.6）+ 标签 `[课表固定|约好的]`；hard 碑菜单首行是说明 +「去了/完成了」「请假，不去了」「标记冲突」——**给死路一条岔路，任何阶段都在**。
- **打勾圈** `.tick`：二态（空 → ✓完成 → 空），`onPointerDown` 必须 `stopPropagation + preventDefault`（否则被拖拽抢走）。
- **待回顾**（`recon && planned`）：右上角呼吸 `?` chip；碑菜单出 `.jg-lapse`「它该去哪儿？」四条出路：其实做了 / 放回想做的事 / 明天再排 / 就这样过去。
- 过期未标**不变红、不积债**——没有红色，没有欠账计数。

## 5. 提案的三态渲染

| 提案 | 渲染 |
|---|---|
| `timed`（L1） | 路上的**虚影路标**：半透明 + 虚线 + 3.2s 呼吸浮动，写着「想放这儿?」；点开 `.jg-pop` 确认卡（就这么办/不了/追问） |
| `card`/`decision`（L2） | 场景前浮起的一张纸 `.jg-prop`（居中偏上，弹簧入场 320ms）；复合提案行级接受/拒绝；队列 >1 显示「还有 N 张」+「先不看」 |
| 追问 | `followUp(pid)` 写 Exchange 快照（TTL 10 分钟）→ 打开伙伴面板，快照以 `.jg-exsnap` 呈现，可收起 |

## 6. 山脊雷达（无月视图的落地）

`radar()` 前 8 条作业/死线 → 地平线剪影 SVG（`viewBox 0 0 100 10`，`preserveAspectRatio="none"`）：峰高按 urgency（2→8.6 / 1→6.2 / 0→4.2），峰位沿地平线均布。**越高越近**。点山脊 → 展望面板（死线清单 + 愿望池），语义是列表不是日历。无死线时画一道平缓远山——好天气。

## 7. 回头面（足迹镜像）

- 过去 48 小时已结束的块按「几分钟前」用**同一个投影函数**向远处退去，全部石化质感——过去不改写，只可注释/重新安排。
- 顶部一行字定调：「石化的是记录，不是欠账」。
- 底部 `.jg-river` 河流条：15 天的操作密度柱 + 心情点（`river()`），点「账本」进 append-only 账本面板（撤销/捞回都在）。
- 回路上：「回到路上」chip。

## 9. 主题（三套天色 + AI 生成）

挂在 `data-jing`。变量表见 `jing.css` 顶部：`dawn` 晓（默认，玫瑰金地平线，light）/ `dusk` 暮（熔金暗紫）/ `night` 夜（蓝黑）。场景分五层上色：`--sky-top/mid/glow`（天）、`--ridge`（山）、`--ground-far/near`（地）、`--road/road-edge`（路）、`--sun`（天体）。类型色 `--c-task/appointment/relax/meal/break`。

AI 自定义主题走 `index.html` 的 `jingApplyTheme()`：12 变量白名单 MAP 覆写（`--primary→--accent`、`--bg-start→--sky-top`、`--bg-end→--ground-near`、`--surface→--card`…），`dark` 基底落到 `night`。**不设 `--error` 映射**——本端没有红色语义。

## 10. 响应式

- `<900px`：手机主客场，竖向拖动手势 + `.jg-lookhint` 提示条。
- `≥900px`：同一场景放宽（顶栏/卡片字号放大，bottom sheet 收到 620px 居中），`.jg-keyhint` 替代手势提示——**不套手机壳，也不改骨架**。媒体查询块排在 `jing.css` 最后。

## 11. 语气与铁律自查

- 「路上还是空的。不是坏事——说明还没人替你着急。」（冷启动诚实空态，无欢迎页）
- 「没做（没关系）」「就这样过去——不积债」「推开了——它会学乖一点」「熬太久了我会喊你歇歇，语气是担心不是训斥」。
- 每个写动作 → `jgUndo` 3 秒撤销条 + operation 入账；新增写操作必须带逆操作（共享核心已保证）。
- 收集 ≤2 秒：底部输入条永远在场，说一句就走；附件直接静默入资料库。
