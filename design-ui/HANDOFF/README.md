# Daycore 交接包 · Handoff to Claude Code

> **一句话**：这是一个「替不擅长规划的人省心的 AI 日程管家」的设计原型仓库。同一套数据契约上并存 **五个范式级不同的前端**。本包的目标是让 Claude Code 在真实工程里 **重建出完全一样的效果**。

---

## 0. 先读这个：这些文件是什么

本包里的 `.html` / `.jsx` / `.css` 是 **用 HTML 写成的设计参考（design reference）**，不是要直接上线的生产代码。它们是「意图的可运行说明书」：颜色、间距、动效曲线、交互时序、文案都是**最终稿**，但工程实现（框架、构建、状态管理、后端对接）应当在目标代码库的既有环境里重做。

- 如果目标项目已有技术栈（React / Vue / SwiftUI / Flutter / 原生），**用它既有的组件库与模式重建**，不要照搬这里的 DOM 结构。
- 如果还没有技术栈，推荐 **React + TypeScript + Vite**，因为原型本身就是 React（JSX + Babel 在浏览器里现场转译），迁移成本最低。
- 唯一必须**逐字照搬**的是 `core/daycore-core.js` 所描述的**领域语义**（见 `01-core-contract.md`）。那不是 UI，那是产品的骨头。

## 1. 保真度

**高保真（hi-fi）。** 五个前端都是可交互的完成品，不是线框图：

- 颜色、字号、圆角、阴影、动效曲线与时长都已定稿，见 `06-design-tokens.md`。
- 交互时序（长按 460ms、阻尼回弹 7px、石化阈值 5 小时…）是产品语义的一部分，**改数值等于改产品**。
- 文案（中文）是定稿，语气经过刻意设计（见下「语气铁律」），**不要改写、不要"优化"成更客气的说法**。

要求：**像素级重建**。左右误差 1–2px 可接受，但节奏、密度、层级必须一致。

## 2. 五个前端

| 前端 | 范式 | 一句话 | 入口 |
|------|------|--------|------|
| **琉璃 `liuli/`** | 长卷 · 时间画布 | 时间是一块连续的空间画布，你在地图上看自己的日子 | `liuli/index.html` |
| **纸屿 `zhiyu/`** | 顺流 · 叙事流 | 一天是一篇由你和小禾共同书写的日志，滚动即时间旅行 | `zhiyu/index.html` |
| **汀 `ting/`** | 此刻 · 单件流 | 画面永远只回答一个问题：现在做什么 | `ting/index.html` |
| **琉璃初版 `liuli-classic/`** | 常规范式 · 页面制 | 底部/侧边 Tab + 卡片列表，作为对照组 | `liuli-classic/index.html` |
| **径 `jing/`** | 远路 · 纵深时间 | 时间是一条从脚下伸向地平线的路，事从远处走近 | `jing/index.html` |

门厅 `index.html` 是五者的入口 + 演示场景切换器。

**它们不是"同一个 App 的五套皮肤"**，而是五种对"日程管家该长什么样"的根本不同回答。共享同一份账本：在任一端接受的提案、撤销的动作，其余四端立刻可见。重建时五端可以分期做，但**数据层必须先统一**。

## 3. 语气铁律（产品的灵魂，不可协商）

这些规则贯穿所有文案与交互，重建时必须保留：

1. **不变红、不积债。** 没做完的事不会变成红色警告、不会累积成"欠账"。过期未做的块只是安静地问「它该去哪儿？」。
2. **任何 AI 动作 3 秒内可撤。** 每个写操作都进 append-only 账本，返回 `opId`，UI 给出撤销入口。
3. **过去不改写。** 超过石化阈值的块变成"记录"，只能补注释或"重新安排"（在未来放一个新的），不能篡改。
4. **AI 说人话，不说客套话。** 例：「没做，没关系」而不是「任务未完成，请及时处理」；「不是坏事——说明还没人替你着急」而不是「暂无日程」。
5. **不许愿式承诺。** AI 提案永远是"想放这儿?"的虚影，用户点头才落地。
6. **给死路一条岔路。** 任何"不能做"的地方都必须同时给出替代动作（改不了课程时间 → 请假 / 标记冲突）。

## 5. 怎么把它接到 Claude Code

见 `CLAUDE_CODE_SETUP.md`（在包根目录）。最短路径：

```bash
unzip Daycore交接包.zip -d daycore && cd daycore
claude          # 仓库根的 CLAUDE.md 会被自动读取
```

然后第一句就说：

> 读 HANDOFF/README.md 和 HANDOFF/01-core-contract.md，先把数据核心用 TypeScript 重写成一个包，不要动 UI。
