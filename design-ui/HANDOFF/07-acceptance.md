# 07 · 重建验收清单

按端逐条勾。**"看起来差不多"不算过**——下面每条都是踩过坑修回来的。

## A. 数据核心（先做完这个再动 UI）

- [ ] `localStorage` key `daycore-v4-core`，四端共享同一份，任一端写入其余三端立刻重渲染
- [ ] `phaseOf` 的石化阈值是 `min(now − 5h, 今天 00:00)`，读时计算
- [ ] 石化块只读：不能拖、不能改时间、不能改状态；只能注释或「重新安排」
- [ ] 每个写操作进 append-only 账本并返回 `opId`
- [ ] `undo(opId)` 对 `01-core-contract.md` §4 表里**每一种** `payload.type` 都有逆操作
- [ ] `bulkBlocks` 把一批块写成**一条**可撤销 op（不是 N 条）
- [ ] `deriveLock`：含「（课）/课程/导论/讲座」的 appointment → hard；其余 appointment → soft；task 类 → null
- [ ] `moveBlock` 对 hard 返回 `{locked:'hard'}`；对 soft 返回 `{locked:'soft', pending}`，需 `to._confirmed` 才落下
- [ ] `agent = true` 可越过锁
- [ ] `patch()` 是**单参数**；`assistantName`/`language` 在 state 根，用 `patch()` 改
- [ ] 三个场景种子都能切，且切换保留 `themes` / `customThemes`
- [ ] 旧数据迁移：缺 `lockLevel` 的块载入时自动补算

## B. 琉璃 · 长卷

- [ ] `.cj-top` / `.cj-bottom` / `.cj-wells` 都是 `pointer-events:none`，只有子元素 `auto`
- [ ] 底部 176px 区域内的块和虚影**能点、能拖、能右键**
- [ ] 桌面右键 → 块浮层；移动长按 **460ms** → 同一浮层（伴 12ms 震动）
- [ ] 长按期间移动 > 5px 取消长按，转为拖拽
- [ ] 虚影与真实块**一起 laneize**，重叠时虚影往右错开 18px/道 + 不透明底 + 描边，z-index 高于真实块
- [ ] 「现在」线是**均匀** 1.5px 实线（不是渐变消失）
- [ ] hard 锁块拖动只跟手 7px → `.tug` 回弹 440ms → toast 说明原因 + 替代动作
- [ ] 引力井 **2×2 四个**：资料收好 / 改天再说 / 交给明天 / 小禾重排
- [ ] 井命中判定：手机内缩 10px，桌面放宽 18px
- [ ] 桌面井体量放大且垂直收到 38%/32%（靠近中线）；手机缩小贴边 8px
- [ ] 块上的锁是**灰色小锁**（不是图钉），`--lock-*` 变量可被主题覆盖
- [ ] 打勾圈是**二态**（空 ↔ 完成），`onPointerDown` 有 `stopPropagation + preventDefault`
- [ ] 标签**最多 3 个**，`nowrap + overflow:hidden`，compact 卡隐藏
- [ ] 打勾圈与浮层标记区是**同一套状态**，随时可改回
- [ ] 锁定块在**任何阶段**都有「请假 / 不去」+「标记冲突」入口
- [ ] 过期未标记块出现「它该去哪儿？」三选：放回想做的事 / 明天再排 / 就这样过去
- [ ] `≥1100px` dock 变左侧 228px 竖栏

## C. 纸屿 · 顺流

- [ ] 四个主题名与底纹**对应**：格线纸=方格 / 行线本=横线+红边线 / 牛皮纸 / 炭黑纸
- [ ] `.dc4-bg::before`（光斑）与 `::after`（噪声）都 `display:none`
- [ ] `.fl-card` 背景是纯 `--dc-surface`，无 grain、无 `background-blend-mode`
- [ ] 便签背景 = 行线 + 一层柔和渐变，**无随机噪声图**
- [ ] 牛皮纸的纸色偏黄褐（`#efe3ce`），不是白纸配橙字
- [ ] 图钉是纯 CSS 径向渐变 + **短硬**投影 + 纸面压凹圈，`--pin-*` 可覆盖
- [ ] `.lk-hard` 实线边框 + 2px 直角色条；`.lk-soft` 只有实线边框
- [ ] hard 锁拖动触发 `fl-tug` 420ms 回弹 + 摆动
- [ ] soft 锁改期时菜单**原地**换成确认层（不是系统 `confirm`）
- [ ] 滚动是唯一导航，「回到现在」用 `scrollTop` 计算（**不用 `scrollIntoView`**）

## D. 汀 · 此刻

- [ ] 移动端：上滑 = 主动作，下滑 = 全天抽屉，左滑 = 推开
- [ ] 桌面端（≥860px）**不套手机壳**：整屏一个问题，内容锁 660px 栏居中
- [ ] 桌面端整个 `@media` 块排在 `ting.css` **最后**
- [ ] 标题字号用 class 三档（`.tg-title` / `.md` / `.sm`），**没有内联 `fontSize`**
- [ ] 桌面键盘：`Enter`/`↑` 主动作、`Esc` 推开、`↓` 全天；输入框内不拦截
- [ ] 桌面显示 `.tg-keyhint` 键位提示，隐藏上滑箭头
- [ ] 底部「下一件」与收集胶囊对齐同一 660px 栏宽

## E. 琉璃初版

- [ ] 样式表是 v3 版那份（75 个类齐全，缺失应 ≤3 个 DS 内部类）
- [ ] 五页都渲染正常，`≥900px` 左侧 rail、`<900px` 底部 TabBar
- [ ] 桥接层：日程/作业/课程/心情/记忆/资料/主题/助手名全部投影自核心
- [ ] 场景切换在初版立刻生效（健康日 3/6、危机日 2/5、冷启动空白）
- [ ] 保存块时**时间未变不产生「挪动」op**（一次保存只 1 条 op）
- [ ] 锁定块能改名（先写字段再判时间，不能因为锁提前 return）
- [ ] 归纳规则 `managed:true`，开关/删除返回 `{error:'managed'}` 且 UI 显示「由共享账本管理」
- [ ] 自存规则：29 → 0 → 29 幂等，停用保留记录
- [ ] 一次规则开关只写 **1 条** op，一步撤销可复原全部占位

## F. 语气与文案

- [ ] 没有红色警告、没有"逾期""未完成"字样、没有累积欠账
- [ ] 每个 AI 动作都有 3 秒内可撤的入口
- [ ] 空状态说「不是坏事——说明还没人替你着急」而不是「暂无数据」
- [ ] 「没做」一律配「没关系」
- [ ] 每处"不能做"都同时给出替代动作
- [ ] 提案永远是"想放这儿?"的虚影，不是已生效的安排
